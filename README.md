# random-super-heroes
This project will randomly display super heroes/villains if a button is clicked

## 🛠️ Technologies utilisées

- Langages : `JavaScript`, `HTML`, `CSS`
- Frameworks : `Node.js`

## 📦 Installation

### Prérequis

- Node.js 
- Un accès à un terminal

### Étapes

```bash
git clone https://github.com/Askoo94/random-super-heroes.git
cd random-super-heroes/
npm install # installer package node
nodemon app.js # lancer le serveur
